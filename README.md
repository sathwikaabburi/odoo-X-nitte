# 📌 About Dayflow

Dayflow is a web-based Human Resource Management System developed for the **Odoo x NMIT Bangalore Hackathon '26**.

The platform provides a centralized solution where employees can manage their HR-related activities while HR and Admin users can efficiently manage employee operations.

Dayflow focuses on:

- Clean role-based architecture
- Secure authentication
- Reliable HR workflows
- Normalized database design
- Simple and scalable implementation

---

# 🎯 Problem Statement

Traditional HR processes often involve disconnected systems for:

- Employee information management
- Attendance tracking
- Leave management
- Payroll handling
- Document storage

Dayflow brings these essential HR operations into a single centralized platform with secure role-based access.

---

# ✨ Core Features

## 👨‍💼 Employee Features

Employees can:

- Securely sign in
- View personal profile
- Update permitted profile information
- Check-in and check-out
- View attendance history
- Apply for leave
- Track leave status
- View payroll details
- Access personal documents

---

## 👩‍💼 HR / Admin Features

HR and Admin users can:

- View employees
- Manage employee information
- View attendance records
- Review leave requests
- Approve leave requests
- Reject leave requests
- View payroll information
- Update salary structures

---

# 👥 Role-Based Access

Dayflow supports three user roles:

| Role | Access |
|------|--------|
| EMPLOYEE | Own profile, attendance, leaves, payroll and documents |
| HR | Employee management and HR operations |
| ADMIN | Administrative HR operations |

Authorization is enforced at the backend level.

The frontend is not treated as the security boundary.
